# BluRock Energy

Duplicate of KPDoyle/nzptechnology at commit 343eb0d7b5b8c7670cddd951bfa7bacee370fcb1, with BluRock Energy branding.

Production: https://blurock-kevindoyle.vercel.app

## Development

Run `npm ci`, `npm run dev`, and `npm run build`. React, React Router, Vite, esbuild, and the original lockfile versions are preserved. Production prerenders all 29 reference routes, with page metadata and a sitemap.

## Scope

Reference layout, typography, palette, image, navigation, solution pages, eight topic directories, search, checklists, calculator, downloadable guides and project brief are preserved. The original colour logo comes from https://blurockenergy.com/wp-content/uploads/2023/11/BluRock-Logo-Color-no-Tagline-PNG-1024x211.png. NZP leadership cards are replaced by equivalent expertise cards; they do not assign NZP officers to BluRock. The plant image remains an illustrative concept.

## Enquiries

BluRock’s existing Jotform 233108375757159 currently displays Over Quota. The duplicate does not send leads to NZP’s Formspree account. The three-step form validates inputs, prepares a downloadable brief, and opens an email draft to Brad@blurock.com, the address published in BluRock’s public pitch deck. Visitors must send the email and attach supporting files themselves. The application does not claim receipt or email delivery.

## Deployment

Vercel project `blurock`, connected to `KPDoyle/blurock`, builds `main` using `npm run build` and serves `dist`. Existing custom domains have not been changed.
